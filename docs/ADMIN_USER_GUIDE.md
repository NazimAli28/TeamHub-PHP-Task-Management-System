# TeamHub Admin User Guide

## Introduction
Welcome to the TeamHub Admin User Guide. This guide will help you understand how to use the admin panel effectively to manage tasks, employees, and monitor performance.

---

## 1. Login Process
- Open your browser and navigate to `http://localhost/teamhub/`
- Enter your admin username and password.
- Click "Login" to access the admin dashboard.

---

## 2. Navigation Overview
- **Dashboard**: Main page for task assignment.
- **Records**: View and manage all task records.
- **Bonus Points**: Award bonus points to employees.
- **Employee Overview**: Monitor employee performance.
- **Summary**: View overall statistics and reports.
- Use the navigation bar at the top to switch between pages.

---

## 3. Task Assignment Workflow
- Go to the **Dashboard** page.
- Fill in the task assignment form:
  - Select the designer from the dropdown.
  - Enter the order number.
  - Select one or multiple work types.
  - Choose the work type category (New Easy, New Hard, Feedback Easy, Feedback Hard).
  - Enter the work amount.
  - Specify the allotted time in minutes.
- Click **Add Record** to assign the task.
- A success message will confirm the task assignment.
- Notifications and sounds will alert you of successful assignments.

---

## 4. Records Management
- Navigate to the **Records** page.
- View all assigned tasks with filters for date, designer, and status.
- Pause or resume tasks as needed.
- Mark tasks as completed or delete records.
- Export data for reporting purposes.

---

## 5. Bonus Points System
- Access the **Bonus Points** page.
- Select an employee and task to award bonus points.
- Enter the number of points and a reason.
- Submit to update the employee's performance metrics.

---

## 6. Employee Overview and Analytics
- Visit the **Employee Overview** page.
- View detailed statistics for each employee.
- Analyze performance trends and points earned.
- Use filters to customize the data view.

---

## 7. Progress Tracking and Summary Reports
- Use the **Summary** page to see overall project progress.
- Review charts and reports on task completion rates and points distribution.

---

## 8. Troubleshooting
- Ensure your database connection is active.
- Check file permissions if pages do not load correctly.
- Verify audio files are in the correct directory for notifications.
- Consult the complete documentation for advanced troubleshooting.
