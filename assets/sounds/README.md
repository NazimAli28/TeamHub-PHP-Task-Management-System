# Sound Files for Notifications

This directory should contain the following MP3 sound files for notifications:

1. `task_assigned.mp3` - Played when admin assigns a new task
2. `new_task.mp3` - Played when employee receives a new task
3. `task_completed.mp3` - Played when a task is completed

## Recommended Sound Characteristics:

- Short duration (1-3 seconds)
- Clear, pleasant notification sounds
- Not too loud or jarring
- MP3 format for compatibility

## Placeholder Files:

You can use any notification sound files you prefer. For testing, you can create simple MP3 files or download free notification sounds from websites like:

- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

## File Structure:

```
assets/sounds/
├── task_assigned.mp3
├── new_task.mp3
├── task_completed.mp3
└── README.md
```
